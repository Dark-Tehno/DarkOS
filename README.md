# Компактная ОС для OpenComputers (1.12.2)

Лёгкая графическая оболочка для OpenComputers с оконным интерфейсом,
файловым менеджером, текстовым редактором, внутрисетевым «браузером»
(связь между компьютерами/серверами на вашей карте) и открытым API
для написания собственных приложений.

Ключевая идея: система работает **поверх OpenOS** (это неизбежный минимум —
сам OpenOS уже есть в EEPROM/на дискете почти у всех и занимает немного места),
но полностью заменяет тяжёлую надстройку вроде MineOS своей собственной,
написанной с нуля и без единой лишней библиотеки, картинки-иконки или
пакетного менеджера. Весь код — это ~9 файлов общим весом порядка 20-30 КБ,
что должно спокойно помещаться даже на диск начального уровня (в отличие
от MineOS, которой нужны единицы мегабайт).

## Требования к железу

- **GPU + экран уровня Tier 2 (рекомендуется) или Tier 3.** Разрешение
  Tier 1 (50×16) слишком маленькое для окон — систему технически можно
  запустить, но пользоваться неудобно. Код сам подстраивает окна под
  реальное разрешение экрана (`gpu.getResolution()`), так что не сломается,
  но комфортно будет от 80×25 и выше.
- **Жёсткий диск** — хватит младшего тира (даже Tier 1, ~1 МБ).
- **Modem или Network Card** — нужен только для приложений «Обозреватель»
  и «Мой сайт» (внутренняя сеть между компьютерами). Без него остальная
  система работает нормально, просто эти два приложения покажут ошибку
  «нет сетевой карты».
- **Internet Card** — не требуется. Протокол «OCNet», описанный ниже,
  работает через обычный modem/network card внутри игрового мира и не
  обращается к реальному интернету.

## Структура файлов

```
/autorun.lua              — автозапуск (кладём в корень диска)
/os/init.lua               — ядро: рабочий стол, окна, панель задач, меню «Пуск»
/os/config.lua              — создаётся автоматически (настройки, например цвет обоев)
/os/api/theme.lua           — палитра цветов интерфейса
/os/api/gui.lua              — библиотека окон и виджетов (кнопки, поля ввода, текстовые области)
/os/api/appapi.lua           — реестр приложений (сканирует /os/apps)
/os/api/netproto.lua         — протокол внутренней сети OCNet
/os/apps/files.lua           — файловый менеджер «Проводник»
/os/apps/editor.lua          — текстовый редактор
/os/apps/netbrowser.lua       — «Обозреватель» — клиент сети OCNet
/os/apps/sitehost.lua         — «Мой сайт» — превращает ваш компьютер в сервер OCNet
/os/apps/netdir.lua           — «Сеть» — видимость в сети + список включённых компьютеров
/os/apps/updateserver.lua     — «Раздача обновлений» — раздаёт /os другим компьютерам
/os/apps/updater.lua          — «Обновление» — скачивает свежие файлы /os с сервера обновлений
/os/apps/settings.lua         — настройки рабочего стола, имя компьютера и информация о системе
/os/sitedata/site.lua         — создаётся автоматически при первом запуске «Моего сайта»
```

## Установка

Скопировать текст файлов в игру можно тремя способами — выберите тот,
что удобнее на вашем сервере:

1. **Через редактор OpenOS вручную.** На компьютере в игре выполните
   `edit /os/init.lua` (программа `edit` сама создаст недостающие папки),
   вставьте содержимое файла (например, через буфer обмена/`Ctrl+V`, если
   у вас есть Clipboard-совместимый ввод, либо построчно), сохраните
   `Ctrl+S`, выйдите `Ctrl+W`. Повторить для всех файлов из списка выше,
   сохраняя точно такие же пути и имена.
2. **Через дискету, отформатированную в творческом режиме / выданную админом.**
   Скопируйте файлы на дискету через инструмент управления
   файлами хоста (если сервер это разрешает), вставьте дискету в компьютер
   и скопируйте на HDD командой `cp -r /mnt/xxx/os /` и `cp /mnt/xxx/autorun.lua /`
   (буква диска дискеты — `xxx`, посмотреть через `ls /mnt`).
3. **Через Internet Card + `wget` (если админы сервера разрешают интернет-карту xотя бы временно).**
   Залейте файлы себе на GitHub (raw-ссылки) или в
   pastebin/gist и выполните на компьютере что-то вроде:
   `wget -f https://raw.githubusercontent.com/Dark-Tehno/DarkOS/main/init.lua /os/init.lua` для каждого файла. Это самый
   быстрый способ, но зависит от того, разрешена ли Internet Card на вашем сервере.
4. **Через установшик(рекомендовано)**
  * wget -f https://raw.githubusercontent.com/Dark-Tehno/DarkOS/main/install.lua install.lua
  * а затем 
  * lua install.lua
  * reboot

### Автозапуск

Положите `autorun.lua` **в корень** диска компьютера. На большинстве сборок
OpenOS для 1.12.2 файл `/autorun.lua` выполняется автоматически при
включении. Если на вашей сборке это не сработало — откройте (или создайте)
`/home/.shrc` и допишите туда строку:

```lua
dofile("/os/init.lua")
```

`.shrc` выполняется гарантированно при каждом входе в интерактивную
оболочку OpenOS, поэтому это надёжный запасной вариант.

Чтобы вернуться в обычную консоль OpenOS изнутри системы — нажмите
**«ВЫХОД»** в правом углу панели задач.

## Как пользоваться

- **Иконки** приложений — в левом верхнем углу рабочего стола, клик запускает.
- **Кнопка «ПУСК»** внизу слева — список всех установленных приложений.
- Окна двигаются перетаскиванием за верхнюю строку (заголовок), закрываются
  крестиком **X** справа от заголовка.
- **Проводник**: клик по строке выбирает файл/папку, кнопки внизу —
  открыть/удалить/новый файл/вверх по дереву.
- **Редактор**: путь к файлу — в верхнем поле, `Ctrl+S` или кнопка
  «Сохранить» — сохранить.
- **Обозреватель**: введите имя чужого сайта (или адрес компьютера) в
  верхнее поле и нажмите «Перейти» либо Enter.
- **Мой сайт**: превращает ваш компьютер в «сайт», который другие смогут
  найти по имени через «Обозреватель». Настройки — в файле
  `/os/sitedata/site.lua` (кнопка «Открыть конфиг» откроет его прямо
  в редакторе).
- **Сеть**: кнопка «Войти в сеть» делает ваш компьютер видимым для других
  (под именем, которое задаётся в «Настройках»); «Обновить список» покажет
  все компьютеры, которые сейчас включены и тоже нажали «Войти в сеть» —
  клик по любому из них сразу открывает его в «Обозревателе». По сути —
  внутриигровой «интернет» между вашими машинами, без нужды помнить адреса.
  Компьютер виден только пока открыто это окно и включена видимость —
  закрыли окно или нажали «Выйти» → компьютер снова не отображается у других.
- **Раздача обновлений**: запустите на «эталонном» компьютере с самой
  свежей версией ОС — он будет раздавать содержимое `/os` по сети под
  выбранным вами именем.
- **Обновление**: на остальных компьютерах — введите имя сервера обновлений
  и нажмите «Проверить»: покажет, какие файлы отличаются или отсутствуют.
  «Обновить» скачает их и запишет на диск, затем «Перезагрузить» применит
  изменения (компьютер перезагружается сразу, без подтверждения — сохраните
  открытые файлы заранее).

## Протокол внутренней сети — OCNet

Простой протокол поверх стандартных сообщений `modem_message`, порт по
умолчанию `4590` (можно сменить в `/os/api/netproto.lua`, но тогда поменяйте
у всех участников сети одинаково).

- Клиент ищет сайт по имени: широковещательно отправляет
  `OCNET_DISCOVER, <имя>`; сервер с таким именем отвечает `OCNET_FOUND, <имя>`
  с указанием своего адреса как отправителя.
- Клиент запрашивает страницу: `OCNET_GET, <путь>` напрямую по адресу сервера.
- Сервер отвечает: `OCNET_PAGE, <заголовок>, <текст>, <таблица ссылок>`,
  где ссылка — `{label = "Текст кнопки", path = "/путь"}`.

Это намеренно простой текстовый формат (без HTML) — читается как обычная
многострочная надпись плюс кнопки-переходы, что и рисует «Обозреватель».
Если понадобится что-то ещё сложнее (например, чат в реальном времени),
протокол можно расширять новыми командами прямо в `netproto.lua`.

### Передача файлов и автообновление

Те же принципы, отдельные команды поверх того же порта:

- `OCNET_MANIFEST_REQ` → сервер обновлений отвечает `OCNET_MANIFEST, <сериализованная таблица>`
  со списком `{path=, size=, checksum=}` по каждому файлу в раздаваемой папке
  (по умолчанию `/os`). Сериализация — через стандартную библиотеку
  OpenOS `serialization`, вручную парсить ничего не нужно.
- Клиент сравнивает манифест со своими локальными файлами (по размеру и
  контрольной сумме — не криптографической, просто чтобы быстро понять,
  отличается файл или нет) и для каждого несовпадающего файла:
  - `OCNET_FILE_INFO, <путь>` → сервер отвечает `OCNET_FILE_META, <путь>, <размер>, <кол-во частей>`
    (или `OCNET_FILE_ERR`, если файла нет);
  - `OCNET_FILE_CHUNK_REQ, <путь>, <номер части>` → сервер отвечает
    `OCNET_FILE_CHUNK, <путь>, <номер>, <до ~4000 байт данных>`.
  - Файлы передаются кусками по ~4000 байт, чтобы не упереться в лимит
    размера одного сетевого пакета в OpenComputers.
- **Безопасность**: сервер обновлений отдаёт только файлы внутри своей
  раздаваемой папки — попытка выйти за её пределы через `../` в пути
  вырезается на сервере. Тем не менее не запускайте «Раздачу обновлений»
  на компьютере, где в `/os` лежит что-то, что не должно быть доступно
  всем в сети.

### Обнаружение компьютеров в сети (presence)

Отдельная и ещё более простая пара команд, на которой работает приложение
«Сеть»:

- Компьютер, нажавший «Войти в сеть», начинает отвечать на широковещательное
  `OCNET_PING` сообщением `OCNET_PONG, <имя компьютера>, <доп. инфо>` (доп.
  инфо сейчас — имя сайта, если запущено «Мой сайт», иначе ничего).
- «Обновить список» в приложении «Сеть» просто рассылает `OCNET_PING` и
  полторы секунды собирает ответы — так и получается список «кто сейчас
  в сети».
- Это специально сделано **добровольным**: компьютер виден, только пока
  на нём открыто приложение «Сеть» и нажато «Войти в сеть». Закрыли
  окно/нажали «Выйти» — компьютер снова невидим для сканирования (хотя
  через «Обозреватель» его всё ещё можно найти напрямую по имени сайта,
  если на нём отдельно запущено «Мой сайт» — это разные, независимые вещи).

## Как написать своё приложение

Любой `.lua`-файл в `/os/apps/` — это приложение. Он должен **вернуть
таблицу** такого вида:

```lua
-- /os/apps/hello.lua
return {
  id   = "hello",       -- уникальный идентификатор
  name = "Привет",       -- имя в меню «Пуск» и на иконке
  icon = "H",             -- один символ-«иконка»
  run  = function(ctx, args)
    local gui = ctx.gui   -- библиотека окон/виджетов (см. /os/api/gui.lua)

    local win = gui.newWindow{ title = "Моё окно", x = 10, y = 4, w = 30, h = 8 }
    win:add(gui.label(1, 1, "Привет, мир!"))
    win:add(gui.button(1, 3, 12, 1, "Нажми меня", function()
      win:add(gui.label(1, 5, "Нажато!"))
    end))

    return win -- необязательно, но удобно для отладки
  end
}
```

Доступные виджеты (все — методы `gui.*`, добавляются через `win:add(...)`):

| Виджет | Создание | Назначение |
|---|---|---|
| Надпись | `gui.label(x, y, text, fg)` | статичный текст |
| Кнопка | `gui.button(x, y, w, h, text, onClick, colors)` | клик вызывает `onClick(win)` |
| Поле ввода | `gui.input(x, y, w, text)` | однострочный ввод; `.text`, `.onEnter = function(text) end` |
| Текстовая область | `gui.textarea(x, y, w, h, lines, editable)` | многострочный просмотр/редактирование; `.lines`, `:getText()`, `:setLines(lines)` |

Объект `ctx`, приходящий в `run(ctx, args)`, содержит:

- `ctx.gui` — библиотека интерфейса (окна и виджеты, см. выше);
- `ctx.net` — клиент сети OCNet (`ctx.net.get(target, path)`,
  `ctx.net.discover(name)`, `ctx.net.makeHost(name, pages, onLog)`,
  `ctx.net.available()`);
- `ctx.appapi` — реестр приложений, `ctx.appapi.get("editor")` вернёт
  приложение-редактор, чтобы открыть в нём файл: `editor.run(ctx, {path=...})`;
  `ctx.appapi.list()` — список всех приложений;
- `ctx.fs` — стандартная библиотека OpenOS `filesystem`;
- `ctx.desktop.setWallpaper(color)` — сменить цвет фона рабочего стола.

Новое приложение подхватится **после перезапуска** ОС (перезагрузка
компьютера или повторный `dofile("/os/init.lua")`), так как список
приложений сканируется один раз при старте.

## Экономия места на диске

Если места всё равно не хватает (например, вы делаете совсем дешёвые
дискеты для рядовых игроков, а не HDD), можно дополнительно сжать код:

1. **Убрать комментарии и пустые строки** — самый простой способ,
   комментарии в этих файлах занимают заметную долю объёма.
2. **Скомпилировать в байт-код без отладочной информации.** На своей
   машине: `luac5.3 -s -o init.lua.compiled init.lua`, затем на компьютере
   в игре просто кладёте `init.lua.compiled` вместо `init.lua` — Lua
   одинаково хорошо выполняет что исходник, что байт-код через `loadfile`.
   Обычно даёт выигрыш по размеру на файлах покрупнее (`gui.lua`).
3. **Не устанавливать неиспользуемые приложения** — просто не кладите на
   диск ненужные файлы из `/os/apps/`, система прекрасно работает и с
   одним-двумя приложениями.

## Известные ограничения и что стоит проверить в игре

Этот код написан и синтаксически проверен (`luac -p`) вне Minecraft —
у меня физически нет доступа к живому OpenComputers, чтобы прогнать его
на настоящем компьютере в игре. Скорее всего заработает сразу или почти
сразу, но по опыту таких проектов на что обратить внимание при первом
запуске:

- Названия клавиш в `keyboard.keys` (`home`, `end`, `pageUp` и т.п.) могут
  чуть отличаться между версиями OpenComputers — если в редакторе какая-то
  клавиша не срабатывает, откройте `/os/api/gui.lua` и подправьте
  соответствующую строку в `TextArea:onKey`.
- Кириллица (русский текст) в полях ввода: печатать «в лоб» с игровой
  клавиатуры кириллицу через события `key_down` в OpenComputers исторически
  проблематично (сами игровые события клавиатуры Minecraft лучше работают
  с ASCII) — отображать русский текст в надписях и файлах ОС умеет
  прекрасно, но ввод новых русских символов с клавиатуры может потребовать
  доработки (например, приёма событий `clipboard` — вставка через буфer
  обмена работает надёжнее прямого набора).
- Автозапуск (`/autorun.lua` против `/home/.shrc`) — см. раздел выше,
  зависит от сборки OpenOS на сервере.
- Названия событий мыши (`touch`/`drag`/`drop`/`scroll`) и их порядок
  аргументов взяты из документации OpenComputers 1.7.x, актуальной для
  1.12.2 — если что-то не кликается, включите `component.isAvailable("screen")`
  проверку и посмотрите реальные события через `event.pull()` в отладочной
  консоли.
- Размер куска файла при передаче (`CHUNK_SIZE` в `netproto.lua`, сейчас
  4000 байт) подобран с запасом относительно типичного лимита размера
  одного сетевого пакета в OpenComputers, но если на вашем сервере лимит
  занижен в конфиге мода — уменьшите `CHUNK_SIZE` там же.

Если что-то не срабатывает — пришлите мне текст ошибки прямо из игры
(Lua обычно выводит номер строки и файл), поправим точечно.
